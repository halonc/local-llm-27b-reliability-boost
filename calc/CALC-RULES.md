# 计算纪律（CALC-RULES）

> 配套工具：`tools/calc/calc.py`（Decimal 精确，禁心算）
> 为什么有这条：三次实测真错全是低级错，不是理解错。
> · H 型钢 119.8 cm² 换算成 **28.1** kg/m（正确 94.0，差 3.3 倍）
> · 1200+380+260+150 加成 **2010**（正确 1990）
> · 2026-10-20（周二）的「本周五」算成 **10-24**（正确 10-23）

---

## 1. 强制走 Python 的范围（硬性）

命中任一条，**不许心算**，必须 `python3 tools/calc/calc.py ...`：

| # | 范围 | 例子 |
|---|---|---|
| 1 | **3 个及以上数字的加减**（或任一多位数加减） | `1200+380+260+150` |
| 2 | **任何乘除**（除 ×2 / ÷2 / ×10 / ÷10） | `1990*1.05/5` |
| 3 | **任何单位换算** | `119.8 cm2 -> m2`、`1065.6 kg -> t` |
| 4 | **百分比 / 损耗率 / 税率 / 折扣 / 摊销** | `1990` 加 5% 损耗 |
| 5 | **任何金额**（合价、总价、分摊、摊销） | `62.5 t × 4850 元/t` |
| 6 | **日期推算**（日期差、工作日、「本周五 / 下周一」） | `date 2026-10-20 本周五` |
| 7 | **统计量**（均值 / 中位 / 百分位 / 环比 / 同比） | 一组报价的均值 |
| 8 | **开方 / 幂 / 对数 / 三角** | `sqrt(2)`、`1.05**5` |

## 2. 可以心算的白名单（其余一律走工具）

- 个位数加减（`7+5`）
- ×2 / ÷2 / ×10 / ÷10 / ×100
- 10 的整数幂、2 的整数幂
- **答案用来做量级判断**（不是最终值）

## 3. 每次计算必须输出「三件套」

```
① 公式 + 换算因子      W = A × ρ,  1 cm² = 1e-4 m²
② 代入与结果           119.8 cm² = 0.01198 m² → 0.01198 × 7850 = 94.04 kg/m
③ 末行自检             自检：单位✓ 加法✓ 量级✓ 工具✓
```

**外加两条**：
- **先给预期量级**（HW300 型钢约 90–100 kg/m）；算出来偏离量级，**必须重算并说明原因**。
- **加法分组校验**：`1200+380=1580`，`260+150=410`，`1580+410=1990`。

## 4. 可直接粘贴的 prompt 块

```
【计算纪律】凡涉及计算，按顺序做，不得跳步：
1. 列公式与单位换算因子（如 1 cm² = 1e-4 m²）。
2. 调 python3 tools/calc/calc.py 求值，禁止心算。白名单：个位数加减、×2/÷2/×10。
3. 先给预期量级；结果偏离量级就重算并说明。
4. 加法分组校验（例：1200+380=1580，260+150=410，合计 1990）。
5. 末行输出：自检：单位✓ 加法✓ 量级✓ 工具✓
```

## 5. 工具速查

```bash
python3 tools/calc/calc.py eval "1200+380+260+150"        # 1990
python3 tools/calc/calc.py eval "1990*1.05/5" --round 1   # 417.9
python3 tools/calc/calc.py conv 119.8 cm2 m2              # 0.01198
python3 tools/calc/calc.py conv 1065.6 kg t --round 3     # 1.066
python3 tools/calc/calc.py pct 1990 5                     # 增量 99.5 / 结果 2089.5
python3 tools/calc/calc.py verify "119.8 cm2 -> m2 * 7850" 94.0 --tol 0.1
python3 tools/calc/calc.py boq rows.txt                   # 批量校验 数量×单价=合价
python3 tools/calc/calc.py date 2026-10-20 "本周五"        # 2026-10-23（星期五）
python3 tools/calc/calc.py date 2026-10-20 "+34d"         # 2026-11-23
python3 tools/calc/calc.py units                          # 可用单位
python3 tools/calc/calc.py selfcheck                      # 三个历史错题回归
```

## 6. 边界说明

- **工具只保证算术正确，不保证公式正确**。公式（该乘还是该除、损耗率放分子还是分母）仍需人工确认；工具不背这个锅。
- `--tol` 默认 0.01；拿四舍五入过的目标值对比时放宽到 0.1。
- 千分位逗号、`×`、`÷`、`^` 都会自动归一。
- 表达式白名单只有 `+ - * / ** ()` 和数字，不执行任意代码。

## 7. 实测：22 类 × 5 题 = 110 题（2026-10-28，Paiton 27B 3-bit）

标准答案全部由 Python（Decimal）算出，模型只回一行「答案=…」。
**总体 102/110（92.7%）**。题库与明细：`tools/model-ab/math_bench.py`、`math-paiton-fixed.json`。

### 7.1 三档结论（按 5 题正确数）

| 档 | 类别 | 正确 | 处理 |
|---|---|---|---|
| **A 可放心自算** | 整数四则 / 小数四则 / 百分比求值 / 百分比反求 / 涨跌幅 / 折扣售价 / 税费反推 / 长度换算 / 面积体积换算 / 重量换算 / 面积周长 / 体积容积 / 速度时间距离 / 密度质量 / 功率电费 | **15 类全 5/5** | 可心算，但仍建议走工具（换数就可能错） |
| **B 建议走工具** | 温度换算 4/5 · 配比稀释 4/5 · 平均加权 4/5 · 单利复利 4/5 · 日期推算 4/5 | 5 类 | 公式/边界易错，**必须**走工具 + 模板 |
| **C 必须走工具** | **小费分摊 2/5** | 1 类 | 组合运算（百分比+除法），**必错** |

### 7.2 8 道错题的真实原因（关键）

| 题 | 标准 | 模型 | 错因 |
|---|---|---|---|
| 小费 240/20%/3人 | 96.00 | 60.80 | 语义：把"每人付"算成别的组合 |
| 小费 95.5/10%/2人 | 52.53 | 5.28 | 小数点错位（差 10 倍） |
| 小费 78/12.5%/2人 | 43.88 | 44.00 | 四舍五入（43.875 → 应 43.88） |
| -10°C → °F | 14.0 | **-14.0** | 符号：负温度公式 |
| 1:2:4 砂含量 | 0.69 | 0.80 | 分子用错（用 2.4/3 而非 2.4×2/7） |
| 加权平均 | 81.67 | 83.33 | 用了**简单平均**（80+90+70)/3 |
| 5 年复利 | 5796.37 | 5767.00 | 指数公式错 |
| 日期差 | 241 | 240 | 边界：含不含首日 |

**结论：8 错里没有一道是"算术"错，全是公式、语义、边界。**
⇒ 工具解决算术，**公式必须靠模板**（见 §7.3）。

### 7.3 公式模板清单（已实现，`calc.py` 子命令）

这 6 类必须用固定模板，只填参数，不许模型自己列式（括号内是命令示例）：

1. **小费/分摊**：`每人 = 账单 × (1+小费率) ÷ 人数` → `calc.py tip 240 20 3` = 96.00
2. **温度**：`°F = °C×9/5+32`、`°C = (°F−32)×5/9`、`°C = K−273.15` → `calc.py temp -10 C F` = 14.0
3. **配比**：`某料 = 总量 × 该料份数 ÷ 份数总和` → `calc.py ratio 2.4 1:2:4 2` = 0.69
4. **加权平均**：`Σ(值×权重) ÷ Σ权重`（禁用简单平均）→ `calc.py wavg 80x3,90x2,70x1` = 81.67
5. **复利**：`本息 = 本金 × (1+r)^n`；单利 `本金×r×n` → `calc.py compound 5000 3 5` = 5796.37
6. **日期差**：先约定含不含首日，脚本默认 `(后−前).days` → `calc.py dates 2026-03-01 2026-10-28` = 241
7. **比例尺**（5/5 已对，仍建议走工具）：统一换算到 mm 再除比例 → 用 `conv` + `eval`

## 8. 两层结构（2026-10-28 定稿）

原来按"日常 / 高数 / 模板"分三层，**没有意义**——反正都要调 calc。简化成两层：

| 层 | 谁做 | 做什么 |
|---|---|---|
| **1** | 模型 | 读懂题，选**子命令 + 参数**。不碰数字。 |
| **2** | `calc` | 全部数值计算（Decimal / sympy / numpy）。 |

**子命令就是公式清单**，选错就错：

| 场景 | 命令 |
|---|---|
| 四则 / 百分比 / 单位 | `eval` `conv` `pct` |
| 小费分摊 | `tip 账单 费率% 人数` |
| 温度 | `temp 值 C F` |
| 配比 | `ratio 总量 1:2:4 目标份号` |
| 加权平均 | `wavg 80x3,90x2,70x1` |
| 单利复利 | `compound 本金 利率% 年数 [--simple]` |
| 日期差 | `dates 起 止 [--inclusive]` |
| 求导 | `diff "x**2*exp(x)" --at 1` |
| 积分 | `integ "(x**2+1)" --from 0 --to 2` |
| 极限 | `limit "sin(x)/x" --to 0` |
| 解方程 | `solve "x**2-5*x+6"` |
| 行列式 / 逆 / 矩阵乘 | `det "1,2,3;4,5,6;7,8,10"` · `inv` · `matmul` |
| 二项 / 组合 | `binom 10 0.3 4` · `comb 52 5` · `comb 6 2 --perm` |
| 统计 | `stat "2,4,4,4,5,5,7,9" --ddof 0` |
| 向量 | `vec dot/cross/norm/angle "1,2,3" "4,5,6"` |
| 复数 | `cplx "(2+3i)*(1-2i)"` |

**入口**：`tools/calc/calc …`（wrapper 自动用 `tools/calc-venv/bin/python`）。
